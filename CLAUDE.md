## Key Shortcuts
- Run full test suite: `composer test`
- Run static analysis: `composer analyse`
- Run code style check: `composer cs:check`
- Run code style fix: `composer cs:fix`
- Check coverage: `composer test:coverage`
- Run examples: `for f in examples/*.php; do php "$f"; done`
